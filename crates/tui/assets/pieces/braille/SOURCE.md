# Piece silhouette masks

These 40-by-40 monochrome masks are derived from the “Chess Pieces in .svg
Format” set by OpenGameArt user `femrek`:

https://opengameart.org/content/chess-pieces-in-svg-format

The source artwork is dedicated to the public domain under CC0 1.0. The masks
normalize the six SVG silhouettes to the original 50-by-50 view box and apply
a binary coverage threshold. Runtime renderers sample each mask into Unicode
Braille dots or opaque two-by-two quadrant mosaics.
